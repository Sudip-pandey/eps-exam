# EPS-TOPIK Grammar Quiz — 125 Questions

EPS-TOPIK व्याकरण क्विज — १२५ प्रश्न, नेपाली व्याख्यासहित।

## What it is / यो के हो

- **125 grammar questions** — "다음 중 밑줄 친 부분이 맞는 문장을 고르십시오" (Choose the sentence whose underlined part is correct). Each question has 4 options.
- **Answers (उत्तर)** come from the book's printed answer sheet at the end of the source PDF — 125/125 verified, none invented.
- **Explanations (व्याख्या)** are in Nepali (Devanagari) for all 4 options of every question — which option fits, which doesn't, and why, with the grammar rule. They are AI-generated and checked against a grounded grammar reference (grammar seed v0.3, 157 entries, grounded in KGIU — *Korean Grammar in Use*). **Verify with a teacher if unsure.**

## Honest notes / इमानदार नोटहरू

- **19 questions** where the book's answer is not the only correct option (another option is also correct, or the marked option breaks the rule). The quiz keeps the book's answer and flags it in the explanation. See [report.html](report.html) for all 19, with the rule and the reason.
- **Most important: Q91** — the book says ③, but the rule (seed + KGIU p. 187) says a command/proposal cannot follow -기 때문에; option ① is the rule-correct one. This is the book's error.
- **Q54** — all four options are correct as printed. **Q106** — options ③ and ④ are the identical sentence printed twice.
- **3 uncertain questions** (Q21, Q75, Q88) — the rule could not be firmly established; flagged, not confidently explained.
- **2 book typos repaired:** Q103 생을 → 생일, Q125 가출 → 가축 (both stay wrong after repair).
- **Underlines:** recovered from the PDF itself (490/500); 10 were never marked in the book (Q113 opt 4, Q114 opt 3, Q124 all 4, Q125 all 4) and were inferred from sentence structure.
